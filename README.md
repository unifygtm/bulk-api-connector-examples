# Unify Bulk API — Example Connectors

This repository is a directory of example custom connectors for the [Unify Bulk API](https://docs.unifygtm.com/developers/guides/request-data/bulk-api).

Each subdirectory is a self-contained example showing how to pull data from Unify in bulk and load it into a destination of your choice. Use them as starting points or references when building your own integrations.

## Examples

| Example                   | Description                                                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`fivetran/`](./fivetran) | A custom [Fivetran Connector SDK](https://fivetran.com/docs/connector-sdk) connector that syncs data from the Unify Bulk API into your warehouse. |

## More examples coming soon
